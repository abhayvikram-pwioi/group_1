## 📌 About

FitHive is a modern and responsive Gym Member Dashboard designed to help users manage and track their complete fitness journey.

The dashboard provides an interactive experience where users can:

- Track progress
- Manage memberships
- View workout analytics
- Monitor activity
- Check upcoming classes
- Customize profile settings

Built using **HTML, CSS, and Vanilla JavaScript** with a clean responsive design.
