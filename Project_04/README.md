# 🎉 UniEvents

UniEvents is a responsive Event Management Web Application built using **HTML, CSS, and JavaScript**. It allows users to discover events, view detailed information, register for events, and enables admins to manage events through an admin dashboard.

---

## 🚀 Features

### 👤 User Features

- User Authentication (Login / Signup)
- Profile Management
- Browse Upcoming Events
- Search Events
- Filter by Category
- Filter by Date
- Event Details Page
- Event Registration
- My Registrations
- Registration Success Popup
- Attendee Count Updates
- Responsive Design

---

### 🛠️ Admin Features

- Admin Login
- Admin Dashboard
- Add New Event
- Edit Existing Event
- Delete Event
- Search Events
- Manage Attendee Count
- Local Storage Based Event Management
