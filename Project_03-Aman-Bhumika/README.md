# 🌦️ Weather & News Aggregator

A modern web application that combines real-time weather updates with the latest news in one place. Users can explore weather information, browse trending news, search articles, and view detailed news pages through a clean and responsive interface.

## 🚀 Live Demo

🔗 https://weather-news-aggregator.netlify.app/

---

## ✨ Features

- 🌤️ Real-time Weather Information
- 🌞 Search Weather by City Name
- 📰 Trending News
- 🔍 Search News by Keyword
- 🏷️ Browse News by Category
- 📖 Detailed News Page
- 📱 Fully Responsive Design
- 🎨 Modern and Clean UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeather API
- GNews API
