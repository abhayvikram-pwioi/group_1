# 📚 Student Progress Tracking SaaS

A responsive **Student Progress Tracking SaaS** web application that helps students monitor their learning journey through an interactive dashboard. The platform enables students to view enrolled courses, track course progress, monitor grades, and analyze their academic performance with visual insights.

---

## 🚀 Features

* 🔐 User Authentication (Login & Logout)
* 👤 Student Profile Dashboard
* 📖 Enrolled Courses
* 📈 Course Progress Tracking
* 📊 Grade Visualization
* 📋 Pending Modules Section
* 📱 Fully Responsive Design
* ⚡ Dynamic Data Rendering
* ⚠️ Error Handling
* 🔄 Loading States
* 💾 Session Persistence
