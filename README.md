FitHive – Gym Member Dashboard

FitHive is a modern and responsive Gym Member Dashboard designed to help users track their fitness journey, monitor progress, manage memberships, and explore gym services through an interactive UI.

The project focuses on frontend development using HTML, CSS, and JavaScript with a clean dashboard layout, responsive design, and interactive user experience.



Features

- Responsive Dashboard UI
- User Registration & Login System
- Membership Plans Section
- BMI Calculator
- Activity Tracking Dashboard
- Reward & Streak System
- Upcoming Classes Section
- Recent Activities Feed
- Statistics & Analytics Cards
- Testimonials & Reviews Section
- Sidebar Navigation
- Interactive JavaScript Components
- Responsive Mobile-Friendly Layout
- Dynamic UI Interactions

---

 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Bootstrap Icons
